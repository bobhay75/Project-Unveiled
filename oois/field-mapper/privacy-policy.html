OOIS Field Mapper privacy policy

Updated September 19, 2026. OOIS Field Mapper is a private field notebook provided by Bobsome1. Privacy questions and deletion requests can be sent to thebobsomest1@gmail.com.

Device notebook

Site names, precise map coordinates, notes, tags, review status and resized photo copies are stored locally in this browser or app profile. Local records are not password-encrypted. Anyone who can use the same unlocked device profile may be able to open them. Clearing application or browser storage, replacing the app, or uninstalling can erase local records, so users should keep private exported backups. OOIS does not include advertising or third-party analytics, sell personal data, or use field records for advertising.

Location, photos and maps

Foreground location permission is requested only after the user chooses Capture GPS. The resulting precise coordinate and reported accuracy are saved in that record. Users can deny permission and enter a location manually. Photos are selected through the device or browser picker and are converted to resized JPEG copies; originals remain outside OOIS. External Esri and USGS map services receive the requested map area, IP address and ordinary connection metadata when their layers are enabled. Choosing No external map stops those tile requests.

Optional account and private cloud storage

Cloud features are optional and require a Firebase email/password account authorized by the operator. Firebase Authentication processes the account email and authentication data. A manual cloud save sends the selected record's precise coordinates, notes, tags, review information and resized photos to that account's isolated Firebase/Google Cloud storage. Cloud actions are not automatic. Other authorized accounts cannot read the primary owner's records under the deployed access rules. Signing out does not erase device records.

Optional Gemini analysis

After a separate confirmation, Analyze photos with AI sends that record's notes, tags and resized JPEG photos through a protected Google Cloud Function to Google's Gemini service. Structured coordinate fields and nearby-record lists are omitted, although photo content and written descriptions can still reveal a place. Gemini output is a hypothesis for documentation support, not authentication, dating or proof of origin. The local documentation checklist does not send data to Gemini and does not inspect images.

Retention, security and deletion

Device records remain until the user deletes them or device storage is cleared. Private cloud records remain until the signed-in user chooses Delete selected cloud copy or asks the operator to delete the account and its associated data. Exported backup files are independent and must be deleted wherever the user saved or shared them. Data sent over the network uses encrypted HTTPS connections. No system can guarantee absolute security; users should avoid recording sensitive locations unless needed and should secure their device, account password and exports.

Children and policy changes

OOIS is a field-research utility and is not designed for children. Material changes to this policy will be posted here with a new effective date before the related release.
