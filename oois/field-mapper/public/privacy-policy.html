OOIS Field Mapper privacy

Updated September 17, 2026. A private field notebook by Bobsome1.

Device notebook

Names, exact map coordinates, notes and resized photo copies are stored in this browser’s IndexedDB. These records are not password-encrypted. Anyone using this device profile can open them. Browser data can be erased, so keep exported backups private and secure. The app does not collect analytics or sell records.

Location and maps

GPS is requested only when you choose Capture GPS. Selecting a map location stores that coordinate. External map providers (Esri and USGS) receive the requested map area and connection metadata. Choose No external map to stop those map requests. Offline record keeping works after the initial online visit; map imagery requires internet.

Optional cloud storage and AI

Cloud features require an explicitly provisioned Firebase owner account. Saving a cloud copy uploads that record’s exact coordinates, notes and photos. Cloud actions are manual. Loading cloud records merges new IDs and preserves local versions. Signing out leaves local records available.

Analyze photos with AI requires confirmation and sends notes and resized JPEG photos to Gemini through a protected Cloud Function. Coordinate fields and nearby records are excluded, but image content and written descriptions may reveal a location. AI output is a hypothesis, not authentication or dating. The local documentation checklist uses words in notes and does not inspect images.

Deletion and exports

Delete device record removes only the local copy. To remove its cloud copy and stored photos, sign in and use Delete selected cloud copy in Cloud settings before deleting the local copy. Exported backups are independent files and must be deleted separately. The site operator must manage Firebase account deletion and any provider retention settings.
