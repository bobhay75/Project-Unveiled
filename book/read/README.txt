PROJECT UNVEILED — STRUCTURED DATA INSTALLER

PURPOSE
Help search engines understand the public site as:
- A WebSite
- A Book
- Thirteen individual Chapters
- An Author page for Robert J. Hayes

WHAT IT ADDS
- WebSite JSON-LD on the homepage
- Book JSON-LD on /book/
- Chapter JSON-LD on Chapters 1–13
- Person JSON-LD on the author page
- Book-to-chapter relationships
- Author and publisher relationships
- Visible page titles, descriptions, canonical URLs, and social images where available

WHAT IT DOES NOT ADD
- No fake ratings
- No fake reviews
- No ISBN
- No purchase offer
- No bestseller claim
- No unsupported publication date
- No promise of a Google rich result

INSTALL
1. Extract this ZIP.
2. Upload install-project-unveiled-structured-data.php into public_html.
3. Open:
   https://bobsome1.com/install-project-unveiled-structured-data.php
4. Expected:
   Structured data installed and verified.
   Verified pages: 16 / 16
   Errors: 0
5. Test:
   https://bobsome1.com/book/
   https://bobsome1.com/book/read/chapter-01.html
   https://bobsome1.com/book/read/about-author.html
6. Use Google's Rich Results Test and the Schema.org Validator.
7. In Google Search Console, use URL Inspection and request indexing for:
   - https://bobsome1.com/
   - https://bobsome1.com/book/
   - https://bobsome1.com/book/read/chapter-01.html
8. Delete install-project-unveiled-structured-data.php from public_html.
9. Keep the timestamped backup folder until testing is complete.

NOTE
Valid structured data helps machines understand content but does not guarantee
special search-result features or higher rankings.
